# 私有文件容量与保留规则

2026-10-11。本项目目前没有自动到期删除、永久清理或杀毒服务。

| 文件 | 容量/限制 | 保留规则 |
|---|---|---|
| 课程课件、任务资料/作业、答疑 | 个人200MB/单份20MB/每上下文20份有效附件 | 元数据引用存在即保留；作业提交后固定；逻辑移除也保留与计容量 |
| 客服工单证据 | 个人100MB/单份10MB/每工单10份（含已移除） | 所有引用包含关闭工单与逻辑移除，持续保留供审计 |
| 咨询附件 | 个人100MB/单份10MB/每会话100份 | 已发附件与消息保留，无撤回/自动到期清理 |
| 教师认证材料 | 原认证上传限制 | 保护所有审核版本的身份证明/学历证明引用 |
| 没有任何上述引用的磁盘孤立文件 | 不从用户元数据容量中扣减 | 至少7天后才可列为隔离候选；隔离后至少保留30天供复核/恢复，当前工具不永久删除 |

三个个人容量端点只查询调用者，无查询用户ID参数，返回真实已用/剩余、已移除保留字节、80%预警与保留说明。页面可刷新，成功上传/移除自动刷新对应容量；读取失败不会展示伪造的可用额度。家长没有上传权限时不显示师生容量。

`tools/file_retention.py` 是**离线、仅命名隔离副本**的受控演练工具。只允许数据库`nurture_gap_acceptance_file_retention_*`与`backend/target/file-retention-rehearsal-*`目录，必须匹配`.retention-scope.json`标记。以当前本地操作者文件权限执行，拒绝主库/生产库、上传运行目录和数据库其他连接。它不是已部署的运营清理API/定时任务。

先inventory生成带批次UUID、绝对作用域、候选size/mtime/SHA256和引用/缺失报告的plan；人工复核后quarantine。每个候选移动前重查所有引用、离线状态和指纹，路径越界、链接/junction、新引用、文件变化、缺失引用都拒绝。只移动到同一隔离目录的`.retention/<batch>/files`，不删除元数据/不扣减容量。审计JSONL包含操作者、时间、意图/结果、批次、文件键和哈希；state支持重复调用及中断后恢复。restore拒绝覆盖已有路径并验证字节/mtime，重复恢复不再移动。

命令（必须先自行建立匹配的离线副本；禁止将主库和在线上传目录填入）：

```powershell
python tools/file_retention_rehearsal.py
python tools/file_retention.py inventory --database <隔离库> --root <隔离目录>
python tools/file_retention.py quarantine --database <隔离库> --root <隔离目录> --batch <计划中的UUID>
python tools/file_retention.py restore --database <隔离库> --root <隔离目录> --batch <计划中的UUID>
```

满额用户应联系运营核查，需要扩容或解除引用/正式销毁策略时另行明确授权与业务保留依据。不能通过移除课件/作业/申诉证据绕过保留配额。7/30天是本地演练候选与恢复窗口，**不是已引用用户文件的自动到期日，也不是法律保留期限**。
