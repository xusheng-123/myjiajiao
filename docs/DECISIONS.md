# DECISIONS — 关键决策记录（只记对未来有影响的）

> 格式：决策 → 原因 → 被否决/替代方案。被否决的也要记，防止重蹈。

## 架构类

- **模块化单体而非微服务** → 当前规模下分布式成本无对等收益；ArchUnit 把边界变成测试（空基线违规 0）→ 否决：直接上微服务 / 放任跨模块直查。
- **PostgreSQL 唯一事实源 + Flyway + ddl-auto=validate** → 结构可追溯、可恢复演练（V1–V10）→ 否决：JPA 自动建表、手改表结构。
- **Caffeine 进程内缓存，限频/验证码/锁定计数可接受重启清零** → 单实例 + 禁 Redis 约束；多实例前需外置（已记录为 P2）。
- **Cloudflare Tunnel 出站反连 + 8080/5432 不出容器网** → 无公网入站端口，攻击面最小 → 否决：开放云服务器安全组端口。
- **Web 前后端同域（/api 路由）为推荐形态；跨源用 www/api 双主机名 + env 注入 CORS** → Cookie 第一方最简 → 否决：Cloudflare Worker 路径代理（无必要复杂度）。

## 安全类

- **HttpOnly Cookie + 内存令牌 + localStorage 仅会话摘要** → XSS 无法读取令牌；CSRF 靠强制 Idempotency-Key 自定义头。
- **刷新令牌单次轮换 + 重用即全吊销；锁定零窗口（每请求直查 DB）** → 防令牌重放、锁定期内无空窗。
- **越权探针（probe_authz.py）作为长期回归** → 首轮抓出 8 个真实漏洞，证明「探针—修复—回归」循环有效 → 否决：仅靠代码审阅声明安全。
- **短信验证码不落日志（含自动化断言）**；登录错误话术统一（防枚举）。
- **支付回调 HMAC-SHA256 + 时间安全比较 + 防重放 + 金额一致**；沙箱生产强制关。
- **支付模式 B（运营线下收款确认）为当前默认**，6 并发实测恰一次成功；C 真实渠道待商户资质，A 沙箱仅内测。

## 产品类

- **监护绑定 ACTIVE 才能代付下单**（PENDING 不算）→ 家长参与做成机制而非口号；有 IT 验证。
- **课堂 = 外部会议链接 + 平台考勤留证**（轻模式）→ 先闭环后增强；RTC 为待决策。
- **课后答疑从站内信消息升级为结构化 Question**（状态机 + 授课关系校验）→ 原实现无法支撑「答疑列表/关闭/权限」→ 保留旧 askQuestion 兼容但新功能走 learning。
- **推荐 = 规则化可解释理由**（擅长/审核/预算/风格/评分/经验）→ 否决：「AI 推荐指数 98%」类无算法基础指标；大模型接入列为未来。
- **学习成长数据只算真实指标**（完成课程数/时长=slot 差值/任务完成率/连续天数）→ 否决：编造「掌握度 92%」。

## 工程与工具类（防重复踩坑）

- **ArchUnit 必须 1.5.1**（1.3.0 解析不了 Java 25 字节码 major 69）；1.5.x 起 `JavaDependency`→`Dependency`。
- **Testcontainers 弃用**（本机 docker.io 拉 ryuk 不通）→ 用本地容器 + nurture_test 库。
- **Angular TeachersApi 抽象类本身即 DI Token**（勿再引 InjectionToken 双 token，曾致 NG0201）。
- **前端局域网访问**：`ng serve --host 0.0.0.0` + 防火墙规则（NURTURE_dev_frontend_4200）。
- **pptx/docx 资产**：站酷小薇艺术字 PNG（jsdelivr 可下、raw.githubusercontent 不通）；IAB 标签页调用间会失联。
