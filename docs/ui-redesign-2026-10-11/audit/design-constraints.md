# 美学硬约束（用户最终确认版，2026-10-11）

> 本文件是用户对全站重构美学方向的逐条确认与修订，优先级高于视觉总监草案。
> 所有设计/实施代理必须逐条遵守。

## 美学意境
- 主题：苏州园林，雨后初晴，润物细无声。
- 关键词：粉墙黛瓦、雨后青苔、雨过天青、框景借景、留白。
- 气质：明亮、安静、湿润、有呼吸感。
- 禁止：古风 cosplay、大面积水墨、国潮元素堆砌、深色底区块、沉重戏剧化。

## 色彩比例与「不要过浅」修订
- 粉墙白 70%｜素笺卡片 20%｜苔青 + 天青 ≤ 8%｜海棠 ≤ 2%（比例不变）
- **用户反馈「现在太浅了」**：在保持浅底大格局不变的前提下，必须增强色彩存在感与对比度：
  - 苔青主色用足饱和与明度深度（按钮/强调处要「润而有力」，不是淡绿水印）
  - 卡片与背景的层级差加大，边框/黛瓦线要清晰可见
  - 标题墨色要足，正文对比度确保 WCAG AA 以上且视觉上不发飘
  - 竹影/远山线稿在 ≤6% 不透明度上限内取足，不要淡到看不见
  - Hero 主视觉色彩更饱满温润（雨后初晴的「润」），不要灰白寡淡
- 全站不得出现深色底区块；CTA、愿景区用新叶浅底或雨雾渐变。

## 园林元素（克制使用，全部轻量 SVG/CSS）
- 框景：Hero 主图或导师照片用月洞门/海棠漏窗作 mask，全站最多 2 处
- 黛瓦线：吸顶导航底部 1px 黛瓦色细线代替阴影
- 远山与竹影：背景极淡线稿，不透明度 ≤6%，静态
- 留白：区块上下间距 ≥96px，每屏只讲一件事

## 动效（"润物"）
- 点击涟漪：按钮按下时苔青涟漪由中心扩散，只用 transform: scale + opacity，≤400ms
- 入场：淡入并上移 8px，240ms，列表错落 40ms
- 悬停：卡片上移 2px，边框从太湖石色变为苔青色
- 禁止：飘雨粒子、持续落叶、视差、水波滤镜
- prefers-reduced-motion 下只保留淡入

## 字体（用户明确修订：覆盖视觉总监草案的宋体方案）
- **标题保留楷体**（书写感）：H1/H2/标语使用楷体族（"Kaiti SC","STKaiti","KaiTi","楷体" 等系统楷体栈）
- 正文用系统无衬线字体
- 楷体只用于 H1/H2 和标语，禁止用于大段正文

## 历史工程陷阱（实施时必须避开）
- 禁止全局 `animation: none` 粗暴禁用动画——会导致 opacity:0 起始的入场元素永久不可见；reduced-motion 处理必须保证内容默认可见，动画只做增强
- 营销页（auth/landing/match）CSS 被 tools/verify_brand_css.cjs 锁定（对基线 096e474 逐条比对 1065 条声明），重构营销页样式时必须同步更新锁的基线机制，不能绕过
