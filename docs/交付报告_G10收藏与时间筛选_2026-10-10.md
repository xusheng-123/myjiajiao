## 1. 收藏功能实现（按钮与列表）

**卡片收藏按钮**（`match.component.ts/html`）：
- 教师卡新增 `btn-fav` 按钮：♡ 收藏 / ♥ 已收藏，`aria-pressed` + aria-label 含科目（"收藏老师（化学）"），可访问性完整。

- 取消收藏：toggle 后仅当 `res.favorited === false` 才从列表移除。
- 四态完备：加载中 / 失败（重试按钮）/ 空态（引导去搜索）/ 列表。

## 2. 收藏状态恢复机制

- 刷新页面 → `ngOnInit` → `GET /matching/favorites` → `favoriteIds` Set → 卡片按 Set 渲染 ♡/♥。
- 走查实证：收藏 1 名教师后 reload，按钮仍为 `♥ 已收藏 [pressed=true]`；`localStorage` 中收藏相关键为 **0**。
- 列表与搜索切换不缓存虚假态：收藏面板每次打开都重新拉真实列表；搜索页重载后从服务端恢复。

- **服务端真实授权面**：`MatchingController` 类级无 `@PreAuthorize`、方法级也无——favorites/toggle 对**任意已登录角色**开放；匿名 403。E2E §19 实测：学生 200、教师 200、匿名 4xx（均如实断言）。

## 4. 时间筛选语义与时区边界

`match.component.ts` 模块级 `withinWindow(iso, filter)`，全部按**用户浏览器本地时区**：

| 档位 | 窗口 | 语义 |
|---|---|---|
| 不限时间 | 全部 | 原始检索结果，不删减（null/过去照常显示原始文案「近期暂无可约时段」/原始时间） |
| 今日可约 | `[now, 当地今日 23:59:59.999]` | 当地自然日剩余时段；过去时段不计入（不承诺已过期档期） |
| 3 天内可约 | `[now, now+72h]` | |
| 7 天内可约 | `[now, now+168h]` | |

- **null / 无效日期 / 过去时间**：筛选启用时一律不显示为可约（`return false`）；未启用时不误删。
- **纯前端 computed 过滤**：切换档位不触发任何网络请求（`filteredCandidates = computed(() => withinWindow(...))`），避免重复检索；计数注记「按可约时间筛出 X/Y 位老师（基于当前检索结果；预约以导师档期实际确认为准）」如实声明过滤基于当前检索快照。
- 空结果空态：「当前时间范围内暂无可约教师。可以放宽时间范围，或切换回不限时间查看全部检索结果」——准确、可操作。
- 入口切换（①↔②↔③）不重置筛选状态（走查验证：7 天筛选跨入口保持）。
- **不承诺档期最终可用**：筛选只过滤真实返回的 `nextOpenSlotAt`，不生成时间、不改预约校验（预约仍以服务端档期校验为准）。

## 5. nextOpenSlotAt 复用（零新接口）

- 数据源：`GET /matching/teachers:search` 现有响应字段 `nextOpenSlotAt`（`OffsetDateTime` ISO 带 Z），来自 `openSlotViewsOf` 最早 OPEN 档期——本轮未新增任何后端接口/表/迁移。
- **发现的既有行为（如实记录）**：repository `findByTeacherIdAndStatusOrderByStartAtAsc` 取最早 OPEN 档期**含过去残留**——历史残留的过去 OPEN 档期会使 `nextOpenSlotAt` 为过去时间（非本轮引入，前端已防御：`t < now` 视为不可约）。走查中用正规 `DELETE /scheduling/availability-slots/{id}` API 清理了教师 13900000001 的 19 条残留（测试数据操作），之后「3 天内」出现非空正例。
- 已知限制：search 无分页（上限 `matching.max-result-size` 默认 20），超出截断——客户端过滤安全，但收藏富集只覆盖检索可见教师，缺席者如实标注。

## 9. 缺陷、限制与未验证项（如实）

1. `nextOpenSlotAt` 为最早 OPEN 档期**含过去残留**（既有后端行为）：前端筛选已防御，但「不限时间」视图仍展示原始值（如过去时间）；已清理本轮发现的所有残留，长期解法（如后端过滤过去档期）属后端改动，本轮范围外，已记录待评估。
2. search 无分页（上限 20）：超出教师不进入富集数据源，收藏面板如实标注；不伪造数据。
3. 收藏面板每次打开重新请求（列表+检索各一次），无缓存——数据新鲜但多一次开销（20 条以内，可接受）。
4. 未登录收藏引导分支不可达（roleGuard 前置），为防御性代码。
5. 移动端 @media(≤560px) 样式经代码审查（括号配平、规则覆盖 fav-item 堆叠），**未实机窄视口走查**（IAB 宿主面板固定 1280px 无法缩窄）——标注 🟡。
6. match.component.css 超 CSS budget 268B（警告）；未为本轮扩预算或删样式（删样式有回归风险，扩预算属配置变更留待专项）。
7. 家长/运营角色对收藏端点的可达性**未实测**（仅学生/教师/匿名实测）；控制器无方法级 @PreAuthorize，理论上任意登录角色可达——前端入口不受影响（仅学生端）。
